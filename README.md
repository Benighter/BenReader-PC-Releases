# BenReader for Windows

A wooden bookshelf for your books and a paper-style place to read.

[Download BenReader for Windows](https://github.com/Benighter/BenReader-PC-Releases/releases/latest/download/BenReader.Windows-win-x64-Setup.exe) · [Latest release](https://github.com/Benighter/BenReader-PC-Releases/releases/latest)

Windows 10 (build 19041) or Windows 11, x64. The installer includes the desktop runtime and checks for Microsoft's WebView2 reading component.

- Covers fit on wooden shelves without being cropped.
- Page-by-page reading is the default, with a paper turn and single or two-page layouts.
- Searchable settings, text selection, notes, bookmarks, native PDF pages and Windows read aloud.
- Update information is signed and downloads are checked before installation.
- Your original books stay in place. Reading data is stored in your Windows user profile.

This repository contains installers, update packages, notices and the corresponding source for the separate LGPL libmobi component. BenReader application source is private.
